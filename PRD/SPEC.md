# 長照安心管家 — PRD v3.0.2 等級規格書

> 建立日期:2026-09-19 · 對齊 SPEC v3.0 契約

## §1 產品概述

### 1.1 問題陳述
居家照護的三大痛點：(1) 家屬與照服員排班難以同步 (2) 用藥與日常照護記錄散落在紙本/LINE (3) 緊急事件聯繫鏈依賴記憶。本案提供「照服員排班 + 家屬即時通知 + 照護日誌 + 用藥提醒」一站化。

### 1.2 目標使用者
- **Primary — 照服員**：智慧型手機，每日到府服務
- **Primary — 家屬**：分散在外地，要隨時知道長輩狀況
- **Secondary — 個案管理師 (照顧經理)**：管理 5-20 個案的多重排班

### 1.3 核心價值主張
> 一支手機 = 排班 + 通知 + 日誌 + 用藥 — 零紙本、即時同步、不再漏訊。

### 1.4 Non-Goals
- ❌ 醫療診斷 / 處方簽（衛福部法規）
- ❌ 真實金流（保險請款不在 MVP）
- ❌ 影像病歷 DICOM
- ❌ 跨國多語

## §2 主要場景

| 場景 | 輸入 | 輸出 | 成功條件 |
|---|---|---|---|
| 排班 | 個案需求時段 + 照服員名單 | 週班表 | 衝突偵測 + 一鍵通知 |
| 家屬通知 | 個案事件 (服藥/就寢/異常) | 推播 + LINE | 5 分鐘內送達 |
| 照護日誌 | 照服員到府打卡 + 紀錄 | 日誌彙整 | localStorage + 雲端同步 |
| 用藥提醒 | 處方時間 + 個案 | 鈴聲 + 確認回條 | 漏服追蹤報表 |
| 緊急聯絡 | 一鍵 SOS | 三方電話輪撥 | 長者跌倒/意識不清時 |

---

## §3 FR (功能需求)

- FR-001: 個案資料 CRUD（姓名 / 地址 / 緊急聯絡 / 用藥清單）
- FR-002: 照服員排班（週/月視圖、衝突偵測、輪班建議）
- FR-003: 通知系統（推播 + LINE + Email，per-event 路由）
- FR-004: 照護日誌（打卡 / 紀錄文字 / 照片 / 體溫血壓）
- FR-005: 用藥提醒（處方時間表 + 漏服追蹤 + 報表匯出）
- FR-006: 緊急 SOS 一鍵三方輪撥
- FR-007: 報表（出勤時數 / 月曆 / 家屬滿意度）

## §4 NFR

- 即時性：通知 < 30 秒送達
- 隱私：個資加密、HIPAA-equivalent 分級
- 離線：localStorage fallback，網路恢復自動同步
